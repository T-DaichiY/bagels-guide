The game and the big picture

The computer thinks of a secret number with no repeated digits. You guess, and it gives clues.

ClueMeaning
FermiA digit is correct and in the right position.
PicoA digit is in the secret, but in the wrong position.
BagelsNo digit is correct.

Example: secret 248, guess 843 gives Fermi Pico.

How the modules fit together

Colour key: blue = control flow, green = creates data, amber = user input, purple = pure function (no input or print).

Method

Build one small module, test it, then move on. Never write the next module until the last one works.

Module spec

Constant 2MAX_GUESSES = 10: tries allowed

Module map

NUM_DIGITS = 3Length of the secret. Max 10, because there are only ten distinct digits. MAX_GUESSES = 10How many tries the player gets.

Change one number and the whole game adapts: no other line needs editing.

Key ideas

  • CAPITAL names are constants: set once, never changed while running.
  • One edit changes the whole game (e.g. 4 digits).
Check it works

Run the file. Nothing happens and there is no error.

Live-coding prompts: Why are these at the top, not inside a function? What would break if we typed 3 everywhere instead?

3Give clues

Goal

Compare a guess with the secret and return the right clue text.

Module spec

Nameget_clues
Inputsguess and secret (strings of the same length)
ReturnsYou got it!, Bagels, or clues joined by spaces
RulesSame digit, same place: Fermi. In the secret, wrong place: Pico. Nothing: Bagels. Clues sorted alphabetically.
Must notprint or ask for input (a pure function)

Module map

clues = ['Pico', 'Fermi'] → clues.sort() → ['Fermi', 'Pico'] → "Fermi Pico". Sorting stops the order from revealing which position was right.

Two shortcuts around the loop: guess == secret returns "You got it!" immediately, and an empty clue list returns "Bagels".

Key ideas

  • Check the exact win first, then score each position.
  • Sort the clues so their order does not leak which place was right.

4Ask for a guess

Goal

Keep asking until the player types exactly the right number of digits.

Module spec

Nameask_guess
Inputnum_guesses, used only in the prompt text
Returnsa valid guess: exactly NUM_DIGITS digits, trimmed of spaces
RuleRepeat while the length is wrong or it is not all digits

Module map

.strip() removes stray spaces, and isdecimal() rejects letters like "ab3".

Key ideas

  • Start with an empty guess so the loop runs at least once.
  • Trim spaces; reject letters and symbols.
Check it works

Type abc, then 12, then 123. The first two are rejected; 123 is returned.

Live-coding prompts: Why does the loop use or and not and? Try 12a: which half of the test catches it?

6Main and play again

Goal

Show the rules once, replay on request, and only start when run directly.

Module spec

Namemain
Inputnone
Doesprints the rules, loops play_once(), asks to play again, says thanks
Entry guardthe game starts only when the file is run directly, not when imported

Module map

The guard means importing this file (for testing) won't start a game.

Key ideas

  • An endless loop plus an early exit is the standard replay pattern.
  • Accept yes, Yes, y, YES by lowering the case and checking the first letter.
Check it works

Finish a game, answer yes: a new game starts. Answer no: it says thanks and stops.

Live-coding prompts: What happens if we remove the guard and import this file from another one?

Common errors

Message or symptomUsual cause

NameErrorA name is misspelled, or something was never imported or defined.
SyntaxError near a def, if, for or while lineMissing colon at the end of the line.
IndexError: string index out of rangeGuess and secret have different lengths.
Game never endsThe counter is never increased.
Secret has repeated digitsShuffle all ten digits and slice, instead of picking random digits one by one.
Debugging habit

Read the last line of the error first, then the line number above it. Add a temporary print to see what a variable really holds.

Challenges

  1. Easy: set the digits to 4, then 5. Does everything still work?
  2. Easy: set the guesses to 5 for a hard mode.
  3. Medium: print how many guesses are left after each wrong guess.
  4. Medium: keep a score of games won and print it on quit.
  5. Hard: let the player choose the number of digits at the start.
  6. Hard: reject guesses with repeated digits (hint: a set removes duplicates).
